# Repository Photos Directory (`/photos`)

This folder is created in your Git repository for uploading and storing photos.

- **For raw assets or repository storage:** You can upload your high-resolution photos, certificates, or lab images directly here.
- **For photos you want to display on the live website:** You can also put them into `/public/photos/` so they can be displayed directly in your web app using the URL `/photos/your-image-name.jpg`.

Supported image formats:
- `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`
